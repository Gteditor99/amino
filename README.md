# amino

personal oh-my-zsh theme

<div align="left">

## Installation

1. Copy `amino.zsh-theme` to your Oh My Zsh themes directory:
   ```bash
   cp amino.zsh-theme ~/.oh-my-zsh/themes/
   ```

2. Set the theme in your `~/.zshrc`:
   ```bash
   ZSH_THEME="amino"
   ```

3. Reload your shell:
   ```bash
   source ~/.zshrc
   ```

## Features

- Left prompt with root indicator and arrow
- Right prompt with current directory path
- Git branch and status indicators (staged/unstaged changes)
- Terminal title showing folder, root status, and shell
